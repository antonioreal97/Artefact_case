# Real-model runs — gpt-5-mini (2026-11-01)

Manual live battery with 24 standalone questions and one 3-turn conversation (27 turns), sent to the API running in Docker with `text-embedding-3-small` and `gpt-5-mini`. Each column is a complete run. The model is nondeterministic, so rounds R5–R7 were run twice. "R8 LangChain" uses `LLM_PROVIDER=langchain` with `openai:gpt-5-mini`; the others use the native OpenAI adapter. "R9 nativo" is the post–commerce-privacy-v9 English-customer-fix regression on the same Portuguese battery.

Legend: ✅ useful answer without human handoff; ↪️ correct human handoff (the customer requested a representative); ❌ safe response or human handoff instead of a useful answer, with the reason recorded. For installment payments, `conflicting_sources` appears as ❌ even when the customer receives the portion on which the sources agree: the store manual has conflicting minimum-installment rules. Run labels are preserved: "Antes de R4" ("Before R4") and "R8 nativo" ("R8 native").

This is not a statistical evaluation: the set is small, was not held out, and was used to find defects. Causes and fixes for each round: `docs/development-process.md` §4.5–4.9.
